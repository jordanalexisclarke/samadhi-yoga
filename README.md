# Samadhi Yoga

Responsive static portfolio for Jordan Clarke, built from the supplied “Yoga by Jordan Clarke.docx” and photographs in Documents/YOGA WEB.

Open index.html locally or serve this folder using any static web server. No build step or dependencies are required.

## Publishing with GitHub Pages

Upload the contents of this directory to the selected GitHub repository. In Settings → Pages, select Deploy from a branch, then main and / (root). The relative asset paths support GitHub Pages project URLs.
